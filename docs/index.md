# itquiz

A quiz that helps a layperson sort out IT terms that get mixed up.

- [Genesis](Genesis.md) — how this system came about, and the decisions taken
- [Data model](DataModel.md) — the three facts entities, the two question entities, the history
- [Types](Types.md) — the enums

> The `unique_…` rows in each class's `## Error Messages` are declared and **not yet shown**: the
> framework attaches those messages to custom validation rules only, so a duplicate still answers
> in English with RAP's own sentence (aide-rap#525). The wording is kept here for when it does.
